# Echoes Temple Builder

Standalone development repository for the Echoes temple-building system.

This project is intentionally separate from the production Echoes app so the builder can be developed, tested, and redesigned without risking the live application.

## Initial goals

- Build temples from reusable architectural pieces
- Choose templates and materials
- Resize and customize structures
- Add/remove architectural features
- Save temple designs
- Export a stable build format that can later be integrated into Echoes

## Integration rule

Nothing in this repository affects the production Echoes app until a finished builder version is intentionally integrated.
